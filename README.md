## 🛠 Tools Used
- Python 3
- VS Code / Any Text Editor
- Terminal / Command Prompt

## 📂 Files
- `calculator.py` → Main Python script

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/developerbhushan/Elevate_Python-Internship-Task-1.git


2. Navigate to the folder:
    cd Python-Internship-Task-1

3. Run the program:
    python calculator.py

## Features
- Supports Addition, Subtraction, Multiplication, Division
- Handles invalid input (non-numeric values, division by zero)
- Runs continuously until user chooses to exit
